I am a full-stack programmer, with extensive experience in web3 development:

- [Iggy](https://iggy.social/): Web3 Social framework, like Wordpress but for Web3 Social. It helps you easily set up a decentralized chat for your community. Open source and free for anyone to use. ([GitHub](https://github.com/iggy-social))
- [Punk Domains](https://punk.domains/): Modular web3 domain protocol that can issue multiple domain extensions. Audited by Protofire. ([GitHub](https://github.com/punk-domains-2))
- [Periodic Staking Rewards](https://github.com/tempe-techie/periodic-staking-rewards): An open-source smart contract which you can use to set up staking with rewards, an alternative to the Synthetix StakingRewards.sol smart contract and similar.
- [Revenue Distributor](https://distributor.iggy.social/): Easily launch a smart contract that can distribute revenue to addresses that you define. ([GitHub](https://github.com/iggy-social/iggy-contracts/tree/main/contracts/distributor))
- [Browser Notes](https://github.com/tempe-techie/browser-notes): Pure frontend app which stores your notes locally in browser storage (no backend, no external libraries).
- [Degen Radio](https://degenradio.lol): A web3 alternative to Spotify where you can create onchain playlists of music NFTs from many EVM chains.
- [Send2.name](https://send2.name/): Send tokens to any web3 domain name, across many different chains. 40+ supported domain extensions.

My main guiding principles are to develop open-source software that anyone is free to fork, to build projects in a way that they are not reliant on me or anyone else and can exist forever, and that bring goodness and freedom to the world.

Smart contracts are built using best security practice, such as OpenZeppelin libraries, static analysis tools like Slither, best practice guidelines such as Solcurity, and AI-supported self-audits.
